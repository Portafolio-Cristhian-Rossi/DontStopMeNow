# Etapa 2 — Web de gestión: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Interfaz web en React, servida por el propio servidor en `http://localhost:4747`, para ver la biblioteca, gestionar listas, configurar carpetas raíz y vincular celulares; más los ajustes de seguridad del servidor que la web vuelve necesarios.

**Architecture:** Nuevo workspace `apps/web` (Vite + React + TypeScript) que consume la API de la etapa 1 con un cliente tipado sobre los esquemas de `@dsmn/shared`. TanStack Query guarda los datos del servidor; un hook de Server-Sent Events invalida las consultas cuando cambia la revisión. El servidor sirve `apps/web/dist` con `@fastify/static` (solo desde la compu) y redirige al `index.html` las rutas de la SPA.

**Tech Stack:** Vite 8, React 19, React Router 8 (API declarativa `BrowserRouter`/`Routes`), TanStack Query 5, dnd-kit (core + sortable), qrcode, Vitest 5 + jsdom + Testing Library, `@fastify/static` 10.

**Spec:** `docs/superpowers/specs/2026-10-22-dontstopmenow-design.md` (§8 Interfaz web, §5 API)

## Global Constraints

- Mismas reglas que la etapa 1: ESM, TypeScript `~5.9.3`, `strict` + `noUncheckedIndexedAccess`, Node `>=22.22`, Prettier, ESLint.
- Paquete `@dsmn/web` en `apps/web`; importa tipos y esquemas de `@dsmn/shared`.
- Textos de la interfaz en español rioplatense ("Agregar carpeta", "Escaneando…"). Sin librería de componentes: CSS propio con variables y modo oscuro por `prefers-color-scheme`.
- La web solo funciona desde la compu del servidor: las rutas sin `access` declarado pasan a ser `admin` (solo localhost).
- Desarrollo: `npm run dev -w @dsmn/web` (Vite en 5173 con proxy `/api` → `http://localhost:4747`). Producción: `npm start` en la raíz compila la web y arranca el servidor.
- Las peticiones de la web no mandan token: van por localhost.

## Review Focus

1. **DNS rebinding:** una página externa que resuelve a 127.0.0.1 manda `Host: evil.com`; el servidor debe responder 403 a cualquier pedido "local" cuyo `Host` no sea `localhost`, `127.0.0.1` o `[::1]` (con cualquier puerto); test en Task 1.
2. **Rutas de Windows escritas a mano** en "Agregar carpeta" (`D:\Música`, con barra final, con comillas pegadas desde el Explorador): la web recorta espacios y comillas antes de enviar; el error 400/409 del servidor se muestra tal cual; test en Task 7.
3. **Recargar la página en una ruta interna** (`/listas/abc`): el servidor devuelve `index.html`, no 404 JSON; test en Task 2.
4. **Lista manual con canciones repetidas o una canción que ya no existe**: el editor usa la posición como clave, no el id, y "Agregar a lista" no duplica canciones que ya están; tests en Tasks 5 y 6.
5. **El QR vence mientras está en pantalla**: se regenera solo al llegar a `expiresAt`, y si el servidor responde 409 (sin red local) se muestra el mensaje en lugar del QR; test en Task 8.
